# Guide de Planification & Exécution de Tâches Atomiques

## Cycle de Développement TDD Obligatoire

Chaque tâche planifiée doit être découpée selon les 5 étapes indissociables :

```text
[RED] Écrire le test en échec ➔ [RUN] Vérifier l'échec ➔ [GREEN] Écrire le code minimal ➔ [PASS] Valider le test ➔ [COMMIT] Enregistrer
```

## Structure des Fichiers de Plan

- Placer tous les plans dans le dossier : `docs/plans/YYYY-MM-DD-<nom-fonctionnalite>.md`
- Suivre scrupuleusement la numérotation des sous-tâches.
